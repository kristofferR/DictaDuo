Implementation and the earlier framework assessment

The Linux interface uses Qt/QML above the existing controller. The Mac app, shared server contract and capture path continue to serve both clients.

What Cotto contributes

The inspected fork uses C++ / Qt 6.8 / QML, a compact settings window, native tray support and desktop portals for shortcuts and paste. It is a useful implementation reference, especially for a future KDE adapter.

  • Study tray lifecycle and permission request handling.
  • Compare portal shortcuts with the existing Linux adapter.
  • Keep its license notices if any code is reused.

What stays DictaDuo

Cotto currently targets KDE/Wayland and local capture/upload. Its compact UI, engine setup and dictionary differ from our cross-device product.

  • Keep our shared server contract and microphone priorities.
  • Keep the existing Mac client and settings organization.
  • Preserve honest delivery outcomes; a sent paste shortcut is not confirmed insertion.
