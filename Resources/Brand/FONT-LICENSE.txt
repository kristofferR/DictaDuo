DictaDuo wordmark: font provenance
=================================

The wordmark spells DictaDuo exactly. It uses the unmodified glyph designs
from Noto Sans Bold, with custom optical spacing for this one word.

Font family: Noto Sans
Font style: Bold (700)
Font version: 2.015; ttfautohint (v1.8.4.7-5d5b)
Source file: NotoSans-Bold.ttf
SHA-256: 3a08a47daa00cade516425c15c57615aef2fd418ec9811a7b9f465088f92cc05

Font license: SIL Open Font License, Version 1.1
Upstream project: https://github.com/notofonts/latin-greek-cyrillic
License reference: https://openfontlicense.org/open-font-license-official-text/

Provenance was verified against the source font's embedded name table and
the accompanying LibreOffice font notices. The full OFL 1.1 text below is
copied from that distribution's LICENSE file. No font binary is bundled
in these assets.

Production source: wordmark.svg contains eight individually editable,
absolutely positioned path outlines. It contains no text objects, linked
assets, external styles, or font dependency. Glyph curves were converted
with fontTools from TrueType quadratics to SVG cubics. All paths use the
inherited currentColor fill and preserve their counter shapes.

Text editing source: wordmark-editable.svg contains live SVG text. Install
Noto Sans Bold 2.015 before editing this file. Font substitution can change
its appearance; never use the live text source for automated exports.

Layout: 1000 font units per em. Original glyph origins, before scaling,
are [0, 726, 1015, 1527, 1956, 2537, 3261, 3901]. Pair adjustments relative
to advance widths are Di -6, ic -10, ct -4, ta -5, aD -18, Du -8, uo -10.
The outline scale is 96/771. Translate x by 2 - 85*(96/771), and reverse y
around the baseline 2 + 761*(96/771). The master viewBox is 0 0 551 100;
ink bounds are x=2 to 548.9883, y=2 to 98. Keep these proportions.
